I study how the way light is measured shapes what a machine can infer about a scene. A single-pixel camera makes this concrete: it records one value per structured-light pattern, so any image must be computed. Three questions follow: what to measure, how to reconstruct, and whether to form an image at all.

- **Now:** Acquisition-aware single-pixel sensing on an optical bench (manuscript in preparation); question answering from measurements with a frozen vision–language model (exploratory).
- **Planned:** Time-domain diffuse optics at Politecnico di Milano: reconstructing 3D optical-property maps of scattering media from photon arrival times.
- **Long term:** Robotic systems that infer physical parameters and interpret their surroundings directly from raw measurements, guided by physical models.
- **Open to:** research collaborations and internships in computational imaging, image-free sensing and machine perception.
