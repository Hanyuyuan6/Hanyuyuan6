# Yuyuan Han · 韩聿源

PhD Student at Xi'an Jiaotong University · Visiting PhD Student at Politecnico di Milano.

I build research code for learning from optical measurements. My work connects measurement design, noise-aware reconstruction, and image-free perception. Current research explores acquisition-aware learning and adapting pretrained models to bucket-detector signals.
